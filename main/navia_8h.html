◆ navia_frame_acquire()

NAVIA_NODISCARD NAVIA_API const uint8_t *const * navia_frame_acquire ( navia_frame_t *  frame,
ptrdiff_t **  strides,
size_t *  nplanes 
)

Make the current frame available for reading.

For hardware-accelerated video decoding, this copies the image contents from GPU to CPU.

Parameters
framePointer to the Navia frame instance.
stridesPointer to store the list of strides/pitch of each plane in bytes. Negative stride means plane is bottom-up. For audio, this always positive.
nplanesPointer to store the amount of planes. For audio, this always writes 1. This can be NULL.
Returns
Array of pointer to each plane, or NULL on failure. Subsequent calls to this function return same pointer.
Note
navia_frame_release must only be called once regardless on how many times navia_frame_acquire is called.
See also
navia_streaminfo_type_plane_count
navia_frame_release

◆ navia_open()

NAVIA_NODISCARD NAVIA_API navia_t * navia_open ( navia_input *  input,
const char *  filename,
const navia_settings *  settings 
)

Open new Navia instance.

The filename parameter acts as a "hint" to backends to try best possible format or to deduce the media format directly. While it's not required, some backends require it, so it's recommended to specify one if possible. When filename is specified, it must be valid UTF-8 string.

Parameters
inputPointer to "input data". This function will take the ownership of the input.
filenamePseudo-filename that will be used to improve probing. This can be NULL, but it's recommended to specify a pseudo-filename (the file doesn't have to exist in filesystem).
settingsAdditional settings to specify. This can be NULL.
Returns
Pointer to Navia instance, or NULL on failure.
Note
When the function errors, the input ownership will be given back to the caller.

◆ navia_prepare()

NAVIA_API bool navia_prepare ( navia_t *  navia)

Initialize decoders.

You can call this once to finalize your stream enablement setup. This will actually initialize all the decoders. Once all the decoder is initialized, changing stream enablement is no longer possible. This is also called by navia_read() if it's not been initialized yet.

Calling this function multiple times is no-op.

Parameters
naviaPointer to Navia instance.
Returns
Is preparation succeeded?
